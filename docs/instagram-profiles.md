# Instagram profiles

One-time changes, made by hand in the Instagram app (the API can't change a profile). Render the images with `npm run ops:preview`, which writes them to `brand/preview/`.

## CalgaryWatch (@calgarywatch)

| Field | Value |
| --- | --- |
| Profile photo | `brand/preview/calgarywatch-profile.png` (stacked CALGARYWATCH wordmark on navy #06162F; stays inside the circle crop) |
| Name | CalgaryWatch · Calgary events & markets |
| Category | Local & Travel Website |
| Bio | What's on in Calgary, checked against the organizer's own page. 🗓 Events · 🥕 Markets · 📍 Neighbourhoods. Free for residents. |
| Link | https://calgarywatch.ca/events?utm_source=instagram&utm_medium=social&utm_campaign=bio |

The bio is 124 characters (the limit is 150). It makes no claims about audience size and doesn't call the account a nonprofit.

**Pinned posts (3)**
1. **How we check listings.** An update post: "Every date is checked against the organizer's own page." Link to /events.
2. **This weekend in Calgary.** The latest weekend roundup. Re-pin it each Thursday.
3. **Your market, every week.** A market post linking to /markets.

## CalgaryDaily (@calgarydaily)

The brand kit was confirmed on 2026-09-25 against the live account ("Calgary Daily | News & Events YYC"). The feed is mostly reels with no fixed palette, so photo posts use the bold black-and-yellow template. To restyle every future post, change `colors` in `brand/calgarydaily.json`.

| Field | Value |
| --- | --- |
| Profile photo | `brand/preview/calgarydaily-profile.png` (CALGARY white, DAILY in the brand yellow) |
| Name | CalgaryDaily · Calgary news & things to do |
| Category | Media/News Company |
| Bio | Calgary, every morning. What's on today, what changed in the city, and where it came from. Sister account of @calgarywatch. |
| Link | https://calgarywatch.ca/?utm_source=instagram&utm_medium=social&utm_campaign=calgarydaily_bio |

**Pinned posts (3)**
1. **Today in Calgary.** The morning roundup format.
2. **Sources, always.** An update post: "Every post names where the facts came from."
3. **Follow @calgarywatch.** Cross-link to the sister account's weekend roundups.
